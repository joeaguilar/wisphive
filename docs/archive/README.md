# docs/archive/

This directory holds **superseded or completed-and-stale documentation** — point-in-time
artifacts that are no longer the live source of truth but are kept for historical reference.

Rules for this directory:

- **Original filenames are preserved** on archival (per the archival convention). Do not
  rename a doc when moving it here; archive it under the name it already had, even if that
  name contains a pre-existing typo.
- **Nothing is deleted here.** Archived material is retained indefinitely. Move docs *in*;
  never reap them out.
- Archive a doc when it has been shipped, replaced, or has otherwise gone stale — for
  example a completed plan-*.md whose work has landed, or a one-off review/demo artifact.
